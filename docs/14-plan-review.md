# 规划审查结论

审查日期：2026-09-22。审查对象为仓库规划、现有程序、已核验赛事页面及开源资料。

## 结论

2026-09-26 状态更新：本文件的 2026-09-22 审查判断保留为立项基线；其中“没有真实 Nexent 调用/可运行部署环境”已由合成链路和本机部署复测关闭。真实场景、资料、领域审核、原创方法收益和独立盲测仍未关闭，所以完整冲奖建设仍不能据此判定通过。

作为“可以照做并据此判断国奖竞争力的完整建设规划”，暂不合格。作为有明确退出条件的可行性验证计划，经本次修订后可以执行。规划完整与实验成功是两件事，不能靠补文档解除外部依赖。

原先把“门禁通过”对应国赛三等奖、把“有台账”对应二等奖，以及把赛题 3 延伸到全球总决赛的表述均撤回。不是因为获奖无法保证就不做计划，而是这三个判断没有足够证据。

## 三个首要阻断

1. 场景与资料未落实。制造业研发实验室是拟议定位，尚无已确认的业务审核人、关联资料包和实际变更记录。没有这些，就无法区分真实需求与为比赛编造的任务。
2. 创新收益未证实。本体生成、图检索、证据定位和规则门禁都有已有工作。按决定影响排序只是待检验启发式，尚未完成相关工作比较，更未优于人工字段表或普通检索。
3. 关键技术链未跑通。现有代码读取手写 YAML；没有真实 Nexent 调用、资料抽取、本体更新或版本发布。实际机器、模型配置、可用经费与队员时间也未落实。

## 两周前置验证

截止 2026-10-05。先完成以下证据，才决定是否进入完整建设：

- 一个有实际工作经历的领域审核人确认“资料变更后的领用复核”确实存在。访谈保留事实、原有步骤和反例，不能诱导对方认可方案。
- 至少 6 份有可处理依据的源文件，组成 2 个关联开发资料包、10 个开发问题。其中包含前后版本差异、一处来源冲突或信息缺失，以及影响结论的表格/图像字段。若只能取得公开资料 + 合成台账，明确限制验证结论。
- 人工先完成同一组任务，记录依据、答案、所用时间和歧义。自动方法不能预先看到待测答案；这些资料仅作开发，不称盲测。
- 确认可以运行 Nexent 的机器、容器服务、模型端点和额度。先由队员提供所需资源事实；不得因为有本地代码就视为平台通过。

如果 10 月 5 日仍拿不到领域审核人或关联资料，这个行业版本不进入完整冲奖建设。只有其他题目有更好的真实资料和用户条件时才提出换题，不能另取一个宏大名称重复相同缺口。时间目标可依真实校赛截止重新排，但不能用无限延期绕过前置检查。

## 第一条可验收演示

截至 2026-10-12，目标是用 Nexent 核验一条资料变更后的历史申请。例如：先前只记录人员资格类别，新制度对该资格增加有效期要求。系统提出关系/属性变更，给出原文，审核后定位受影响申请；申请时点和制度适用范围均由程序核对。这个例子只是开发假设，必须由实际资料和审核人证实后才能作为行业案例。

验收时必须能指出：哪条 schema 变了、哪些只是事实变了、哪份制度生效、哪个工具做了计算、为什么某条申请受影响，以及冲突时为何没有作出决定。若现有内核不支持该语义，先按架构定义转换或扩展，不能借 v2 预写开关冒充新制度学习。i01 仍作为另一个教学回归演示保留。

首个版本仅需要文件导入、原文证据、变更/复核结果三块界面。默认所有真实流程都只做旁路或历史回放。供应链采购、摄像头、门锁、大规模图谱和多行业产品不进入首轮。

## 资源和分工

2026-09-22 会话内只读检查显示本机总内存约 15.8 GiB，当时可用约 1 GiB；Docker 客户端有版本，服务端未返回版本。这是当时状态，不代表机器永远不足，也不能断定 Docker 没安装。Nexent 官方 README 当次列 Docker 部署最低 8 GiB、推荐 16 GiB；整机总内存不等于项目可用内存，OCR/模型也有额外需求。

首轮优先使用可用的专用环境或释放资源后实测，不购买机器、不自动开云资源。模型推理可用已授权的服务；不承诺在该机器同时运行 Nexent、全套图服务和本地大模型。

| 工作 | 责任 | 试验前应确认 |
| --- | --- | --- |
| 程序、MCP、界面、日志、对照脚本 | AI 主导，队员检查 | 项目范围和可调用环境 |
| 联系资料、解释流程、授权 | 一名队员牵头 | 实际联系人和可处理范围，不自动联系外部人员 |
| 领域标签与规则适用审核 | 导师或业务人员 | 确有领域能力；不能让 AI 兼任最终裁判 |
| 盲测保管、冷启动、账单核对 | 未参与调参的队员 | 测试标签隔离和原始日志 |
| 演示与问答 | 参赛队员 | 能解释数据、算法、代码、局限与失败案例 |

首轮真人时间粗估：访谈与整理 2–4 小时、领域核验 3–6 小时、环境准备与独立复现 3–6 小时，合计约 8–16 小时，需由队员确认。它不是已经承诺的投入，也不含后续数据标注与答辩。人员不足时缩小验证规模并降低结论强度，不虚构独立评审。

费用按实际请求数、输入/输出 token 单价、OCR 用量、主机小时和存储估算；先记录单份资料试跑成本，再推算总量。初轮建议上限为 100 次模型调用、2 次重试/任务作为工程限流，不代表收费授权。付费调用与云资源上限未获用户授权时只使用既有允许额度或本地接口测试，后者不算 Nexent 在线验收。具体报价与总预算目前待落实。

## 自审判词

- “当前项目足以冲国奖”：撤回。程序可复现不能支持比赛竞争力结论。
- “这是创新算法”：降级为假设。需完成相关工作核对、公平基线和消融。
- “确定性程序所以安全”：改为“给定正确输入与适用规则时可重复执行”；抽取、来源或规则错误仍会导致错误决定。
- “AI 可以全程独立完成”：改为“AI 可主导软件与材料工作”；数据授权、领域判断和答辩不能托管为虚构完成。
- “先做更多功能再验证需求”：调整。先做两周前置验证，再投入完整建设。
