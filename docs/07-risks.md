# 风险

- 赛题匹配不足：只有 v2 通过、v3 失败的原型，没有覆盖低资源本体与真实 Nexent 链路，不能据此判断奖项竞争力。
- 混存表过粗：答辩时主动说明这是教学简化表，并指出要换成学校制度的位置。
- 评测泄漏：原 H 集冻结，不继续追加；新行业实验按来源家族另设盲测，不能用模型生成标签自证。
- 没有行业资料或领域审核人：业务价值与正确性缺乏验证，正式建设前就要检查，不能拖到国赛前再找。无台账不写落地，不将有无台账机械对应奖项等级。
- 技能口头改判：现场会被追问击穿。契约禁止改判，演示时当场再跑命令。
- 写成使用教程：超出比赛和安全边界。仓库不写配制、反应和使用步骤。
- 场景偏校园：商业落地分不一定高。不夸大市场。有真实单位以后再谈试点。

总体判断见 [规划审查](14-plan-review.md)：当前仅适合小规模可行性验证，尚不满足完整冲奖立项条件。
