# 公开制度与合成台账开发包

资料由 AI 从公开的教育部、政府部门及高校网站取得。文件登记见 `data/public/official-lab-safety/manifest.json`；范围为公开制度短引文与明确标记的合成台账，没有实际学校的内部人员或库存记录。

原始 PDF/HTML 和浏览器正文提取存于 `.runtime/public-source-research/`。四份本轮完整来源的请求URL、最终URL、HTTP 200、采集时间及原字节 SHA256 见 `official-fetch-manifest.json`。另外两份已保存的是浏览器生成的 Markdown，不冒充原始 HTTP 字节。

开发包只含注明出处的短引文；完整网站与原文件保存在本地采集目录。教育部网站声明禁止商业性的原版原式转载；本项目不把公开可读解释为网站全文的开放再许可。PDF摘录删除排版换行、空白和印刷页码，规范化方法保留在 manifest 中。21条片段与保存正文的字面核对收据为 `artifacts/public-source-quotation-verification.json`。

## 两个开发资料包

人员准入包关联培训/考试、风险等级、重大隐患和准入条款，配合缺少培训或授权证明的合成记录。制度变更包关联台账、出入库登记、历史与现行记录期限、危险源变更和公开校内整改要求。

两个包共享固定制度参考。6个文件属于3个来源家族；2包与10题是开发材料数量，不能算独立盲测样本。两份 CSV 的 kind 为 synthetic，哈希受校验，但没有被导入业务快照或用于领用判定。10题的 label_status 为 developer_authored_unreviewed，尚非领域金标准。

## 可演示的制度差异

`PUB-Q06` 联读2023规范第二十五条（PDF第10页）和已施行法律第四十一条。前者的某类登记资料至少保存1年，后者在剧毒化学品及储存数量构成重大危险源的其他危险化学品范围内要求收发记录至少保存3年。记录类型、品类、数量、适用日期和本校制度必须分别确认。系统保留两条引文并标记待复核，不把旧文字直接变为2026年的统一业务规则。

## 复现与结果

```powershell
.venv/Scripts/python.exe scripts/verify_public_corpus.py
```

命令首先检查 manifest、摘录及 CSV 的原字节哈希、逐行引文、路径和跨文档引用闭包；随后每个包使用独立临时 Workspace，仅导入该包公开摘录，external_model_allowed=false。日常工作台数据库不被改写。返回引用同时保留本地 Ln、原文条号/页码、URL和摘录文件 SHA256。

当前收据 `artifacts/public-corpus-verification.json` 记录6源、21片段、2包、10题，找到预先登记的20/20个定位。指标名为 developer_fixture_locator_recall，范围是开发问题的词法检索覆盖。未测量回答准确率、语义多跳质量、行业安全率或法律合规。

报告中的 needs_review/decision=null 是未审核资料的展示边界，未调用业务 checker；它不能作为“十题业务决定都正确”的结果。下一步先复核领域标签，再以独立来源家族评测检索、关系提取和变更影响。
