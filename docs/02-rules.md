# 判定规则

这是教学用简化规则，不能代替国家标准、消防规范或学校危化品制度。接入真实库房前，混存对必须换成学校公布的禁忌表。

2026-09-22 审查补充：这里“同一人当天未归还类别冲突”是为测试编写的假设，不能证明实际共柜、共区或接触；学生数量系数 0.5 也不是已核验的制度。原文件和案例冻结为教学基准，不能直接迁入行业流程。真实约束必须另外登记适用物料、物理位置、来源、生效期、单位与专业审核结果。

## 类别

FLAMMABLE、OXIDIZER、ACID、BASE、WATER_REACTIVE、TOXIC、COMPRESSED_GAS、GENERAL。

## 简化混存对

下面每对类别不能在同一天的未归还领用里共存，也不能把一种放进只允许另一种的柜子：

- 易燃与氧化剂
- 酸与碱
- 遇水易燃与酸
- 遇水易燃与碱
- 遇水易燃与氧化剂
- 遇水易燃与易燃

## 数量

- 每种化学品有单次上限。
- 学生实际上限等于单次上限乘 student_fraction。v1 和 v2 都是 0.5。
- 教师实际上限等于单次上限。
- 批准数量取申请量、实际上限、在库量的最小值。
- 批准数量等于申请量则放行；大于 0 但更小则限量。

## 顺序

命中后停止。

1. 数量小于等于 0：打回，INVALID_QUANTITY。
2. 申请人、批次或目标柜不存在：打回，UNKNOWN_REQUESTER、UNKNOWN_LOT 或 UNKNOWN_CABINET。
3. 申请人停权：打回，BANNED_REQUESTER。
4. 批次过期或破损：隔离，LOT_NOT_ISSUABLE。这一步先于冲突检查，避免坏批次被普通打回后流回普通柜。
5. 仅当规则卡打开 deny_students：已知学生打回，STUDENT_BLOCKED。未知申请人仍按未知编号处理。v1 和 v2 关闭此项。过期或破损已经在上一步隔离。
6. 没有该类别授权：打回，CLASS_NOT_AUTHORIZED。
7. 目标柜不允许该类别：打回，CABINET_INCOMPATIBLE。
8. 仅当规则卡打开 session_incompatibility：当天未归还类别与本次冲突，打回，SESSION_INCOMPATIBLE。v1 关闭，v2 打开。
9. 在库量为 0：打回，OUT_OF_STOCK。
10. 批准数量小于申请量：限量。上限更紧用 ISSUE_CAP，库存更紧用 STOCK_SHORT；一样紧用 ISSUE_CAP。
11. 否则放行，ALLOWED。

## 版本

- v1：没有同一天冲突检查。这是基线，文件不覆盖。
- v2：打开同一天冲突检查。只有门禁通过才能成为当前版本。
- v3：学生申请一律打回。这是反例，门禁必须拒绝。

v2 对应的事故是：同一个人同一天先领走冲突类别，再领另一种。两次分开看都像能过，合在一起不能过。v1 放行第二次，v2 打回第二次。
