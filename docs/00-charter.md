# 格物镜 · OntoLens 项目章程

状态日期：2026-10-09。赛季为第十一届华为 ICT 大赛 2026–2027 中国区，报名已完成。官方要求与来源见[来源核对](11-sources.md)，当前软件规划见[里程碑](37-teammate-handoff.md)。

## 定位

OntoLens 面向实验室危化品领用的旁路核验与证据追踪。申请、授权、批次、库存、柜位和规则绑定到同一份快照，程序返回 ALLOW、DENY、LIMIT、ISOLATE；证据不足时返回 `needs_review`、`decision=null`。软件不执行真实出库，不替代本单位专业审核。

业务入口支持空库、登录权限、授权资料导入、候选检查、发布、核验、复核和导出。演练资料须标明合成或公开来源，领域适用、行业价值和方法收益依靠独立评测建立。

## 技术与展示目标

- 在 Nexent 中完成有实际任务的 Skill 与 MCP 编排，决定由程序生成。
- 让每项结论能回到来源、定位、原文、快照和规则版本，并能离线重新计算。
- 验证低资源本体候选与变更审核的贡献，在相同资料和人工预算下与公平基线比较。
- 提供清楚、好用且可复现的界面、部署方式、模板与说明。

## 证据要求

软件通过、一次平台调用、合成留出成绩、真实业务效果与正式提交分别验收。对外数字必须能回到命令和原始收据，不把模型自评写成准确率，不把教学规则写成法规认证，不虚构试点、专业审核或原创性。

## 成功条件

材料具有完整的来源与复现入口，业务任务有授权资料与独立标签，模型与确定性内核的边界可以现场验证；演示包含失败、缺件和恢复。国奖是持续建设目标，功能数量和样本数量不对应获奖保证。
