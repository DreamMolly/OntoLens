# OntoLens 推进顺序

状态日期：2026-10-09。报名已完成。当前建设与验收以[里程碑](37-teammate-handoff.md)为准；实际校内及官方截止按有效通知核对，不用内部目标日期代替官方安排。

## 已有基础

核心工作台、四角色权限、六台账导入、候选检查、版本发布、核验、复核、导出与 D1.1 界面已实现。合成规则留出与反事实是冻结工程夹具，平台、模型、容器和 UI 各有独立检查入口。

## 下一阶段

1. 取得经授权的真实旁路任务及资料，核对字段、制度版本与可处理范围。
2. 建立独立领域标签与对照协议，报告错误放行、误拒、定位、成本和人工耗时。
3. 在独立新机器完成启动与备份恢复，保存当前工具、模型、权限和来源验证。
4. 完成真实设备、读屏、原生缩放和失败恢复任务，优化体验并保留验证证据。
5. 依据当前真实结果整理正式模板、演示与代码说明，提交前核对官方要求。

每次推进用新的可核对结果关闭对应条件。资料或外部条件不足时继续独立的软件与公开资料工作，不虚构完成、不重复把未改变的检查当作新进展。可拓展方向见里程碑，研究主张无优势时缩小范围。
