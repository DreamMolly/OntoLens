# 产品范围

本页的人员和四种决定描述现有教学原型。拟升级范围见 [新规划](09-award-plan.md)，建设前提见 [规划审查](14-plan-review.md)。初期仅做历史回放/旁路审核，不连接真实出库或门锁。

## 用户

- 申请人：学生或教师，发起领用。
- 库管：核对程序结论和证据，承担真实流程的人工作业职责；不能修改记录冒充程序输出，但可以拒绝采纳并记录原因。
- 规则管理员：只能提交新规则卡，不能直接把它标成当前版本。
- 评委：看同一条申请在不同版本下的决定，以及升版为什么通过或失败。

## 四个决定

- ALLOW，放行：按申请数量出库。
- DENY，打回：这次不发，保留理由。
- LIMIT，限量：只按 approved_quantity 出库。批准数量必须大于 0 且小于申请数量。
- ISOLATE，隔离：该批次退出流通，不发给申请人。

打回和隔离没有批准数量。

## 一次申请

申请只包含编号、申请人、批次、数量、目标柜，以及该申请人当天尚未归还的危害类别。化学品、类别、库存和批次状态由目录查出。申请人不能提交“请判通过”。

## 已有原型范围

- 合成教学目录：人员、化学品、批次、柜子。
- 版本化规则卡和确定性判定。
- 回归、事故、留出三套案例。
- 升版门禁和命令行。
- 一份 Nexent 技能契约。

## 原型未实现与持续边界

- 网页尚未实现；后续只安排证据与变更审核界面。门锁、摄像头、采购和财务不在计划内。
- 接入真实台账。以后可以换数据来源，本阶段不能写成已经接入。
- 自动发明安全规则不在计划内。候选本体关系可由模型提出；安全约束必须有来源和领域人员批准。
- 替代安全数据说明书、学校制度和教师责任。
