## 验证口径

完整软件结果以 `artifacts/local-validation-report.json` 为准，专项与全量有重叠不能相加。平台和模型看实际调用、observed_at、工具轨迹及来源；容器看本次业务与重启持久化收据。

资料授权声明、schema/hash 和规范化一致性不证明真实性或专业适用；账户身份不认证专业资格。模拟视口与 CSS zoom 不等于真实设备、读屏或浏览器 UI 缩放，界面操作通过不能推导行业安全效果。

## 演练

1. 用独立业务数据库和账户启动 8768，确认 operational_empty。
2. 导入六台账并查看原始/规范化来源、错误提示、候选检查和影响。
3. 管理员确认发布；演示 expected_active 冲突拒绝覆盖。
4. 操作者核验并打开原文；编辑申请使结果 stale，历史导出仍指向原 run。
5. 复核者追加补件，身份来自登录会话，原决定不改变。
6. 展示 Nexent/JEV 真实状态及不可用降级，私有原文不外发。
7. 操作图标折叠、拖宽/键盘调宽、日期与窄屏；导出离线重算后退出。

## 可拓展优化

真实字段映射、组织隔离与逐文档权限、独立检索/解释评测、受影响候选排序对照、真实设备与读屏、断网未知写入对账、签名/备份与持续负载均可继续建设。每项扩展保持程序决定权、来源权限与版本绑定，用实际新结果关闭对应待验条件。
