# 数据与标注契约

状态：规划，尚未收集真实数据。所有资料在进入仓库或演示前必须完成来源与授权登记。

## 目标资料包

每个资料包描述一次可以被旁路审核的领用核验场景。首轮统一为至少 6 份源文件、2 个开发资料包、10 个开发问题；“文件”和“独立资料包”不能混作样本数量。每包至少三类来源，可共享已声明的通用制度；这两包全部用于开发，不宣称独立盲测。规模扩大前先复盘资料质量和标注一致性。

一个资料包至少包含以下来源中的三类，其中一类必须是表格或结构化清单：

1. 安全说明或物料属性文档，提供名称、危害类别或储存限制的来源。
2. 库存、批次、位置或有效期表格，提供数量、状态和位置的来源。
3. 领用、培训、审批或存放制度文档，提供业务约束和生效时间的来源。
4. 扫描图片、标签或表单，只有其中的内容实际影响一个测试问题时才算多模态输入。

资料包不得包含配方、反应、提取或绕开管理的细节。系统只做资产识别、合规核验与旁路决策复核。

## 来源登记

每个原始文件创建一条来源记录，至少包含：

- source_id、原文件名、文件哈希、采集日期和版本号。
- 来源类型、发布主体、公开链接或提供人、可读/可处理/可开源范围。
- 生效起止时间、敏感字段和脱敏方法。
- 页码、表格单元格或图片框定位方法。
- 是否参与开发、验证或最终盲测。
- 是否允许将该文件的已提取文本片段发送给可选外部模型，以及授权依据。

按资料的公开条款或提供方授权，分别记录允许阅读、处理、外发和再分发的范围。未确定范围时先查询条款或询问提供方，不默认“仅队内使用”就合法。真实台账取得所需授权后使用最小脱敏字段，不收集姓名、学号、联系方式等不必要个人信息。

工作台将这项要求实现为 external_model_allowed：默认 false；私有资料不能开启；初始合成来源可开启用于 JEV 开发验证。JEV 只收到当前快照内明确允许外发的文本片段，不能读取图片二进制、原始私有文件或未发布上传资料。

## 图谱事实与候选

每条已确认事实保存：实体或关系 ID、规范化值、source_id、定位、原文片段、版本、生效时间、审核人和审核时间。候选额外保存抽取器版本、模型版本、提示版本、运行时间和候选状态。

候选状态只能是 proposed、approved、rejected、superseded。模型输出必须先是 proposed；只有指定审核人批准后才能写入当前图谱。冲突资料同时保留；发布时间较新也不自动具有更高效力。需要同时核验权威主体、适用范围、生效时间、明确替代关系与审核结果，不能让模型静默选择。

本体类型/关系定义、实体事实和安全规则分别存放。每个本体候选记录 schema_delta、定义、关系端点、至少一个有效实例和来源；只补一个别名或库存量的事实不算本体更新。缺少可审依据时仅展示 proposed，不进入业务判定。

## 标注与金标准

每个跨文档问题先由一名标注人写出：期望事实、预期图路径、支持证据定位、允许结论、禁止结论和是否应交人工复核。另一名非开发者复核歧义；不同意见保留为 adjudication 记录，不能用模型裁决金标准。

问题需覆盖：

- 名称或别名消歧。
- 批次状态、库存或有效期与制度相结合的核验。
- 两份来源在时间、位置或授权上的冲突。
- 证据缺失时的人工复核。
- 制度或资产更新后，受影响的决定路径。

## 划分与封存

首轮两包仅作开发。正式实验再按来源、模板家族和版本血缘切分开发、验证、盲测；同一机构或制度的前后版本属于同一组，不分散到多个集合。共享通用标准可以存在，但必须声明为所有方案都可读的固定参考，不能把它算成独立测试来源。

未参与优化的队员保管盲测问题、标签和未公开资料清单。冻结代码与配置后由测试执行方装载测试资料；被测系统需要读输入才能回答，但开发者不能利用测试标签或错误清单迭代。代码仓库自身没有物理隐藏能力时，不宣称“开发人员绝对不可见”。

现有 H01–H60 不修改、不重新命名、不并入新的行业盲测。它们只作为原规则内核的冻结合成回归基准。新图谱实验需要独立资料、标签和评测报告。

## 队员交付物

| 角色 | 最小交付物 |
| --- | --- |
| 场景联络人 | 来源授权记录、访谈纪要或公开资料说明 |
| 领域审核人 | 数据字典、金标准和歧义裁定 |
| 工程实现人 | 可追溯抽取日志、图谱版本、可复现脚本 |
| 独立复核人 | 盲测封存记录、复现记录和问题修订记录 |

未拿到领域审核人或可核验资料时，可以完成合成概念验证，但所有材料必须写“合成资料验证”，不宣称真实行业效果或落地。

若采用公开资料，准确标为“公开资料验证”；若再配合虚拟台账则标“公开资料 + 合成台账”。这三种来源不能混称真实脱敏台账。没有审核人的问题只能保留草案标签，不能称金标准。
